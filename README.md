# Kotlin Website — React Router 7 Migration

This is a migration of a implified version of https://kotlinlang.org, created for the JetSites 2026 internship test assignment.

## Running

Docker is required to run locally. From the root directory of the project run:

```
docker compose up
```

After that, the site will be available at http://localhost:3000.

The site contains only the home page.

The site is built with React Router 7, React, TypeScript, and Vite.
